## Project Saya

<details>
<summary><b>Rebung Pintar (Project PBL) - IoT Monitoring System</b></summary>
<br>

> IoT monitoring app for environmental tracking, built with **Laravel** and **TiDB Cloud**.

**Tech:** `PHP` `Laravel` `TiDB Cloud` `MQTT` `Vercel`

**Highlights:**
- MQTT sensor data ingestion in real time
- Live monitoring dashboard with interactive charts
- Deployed to Vercel with SSL
- TiDB Cloud as a MySQL-compatible managed database

Live: [project-pbl-tan.vercel.app](https://project-pbl-tan.vercel.app/) · Repo: [DwiBInaFitriono/Project_PBL](https://github.com/DwiBInaFitriono/Project_PBL)

</details>

<details>
<summary><b>Bimbingan Konseling - Student Counseling System</b></summary>

> Web-based student counseling management system built with **Laravel Blade**.

**Tech:** `PHP` `Laravel` `Blade` `MySQL` `Vercel`

**Highlights:**
- Student counseling record management
- Dashboard for teachers and students
- Role-based authentication
- Deployed on Vercel

Live: [bimbingan-konseling-three.vercel.app](https://bimbingan-konseling-three.vercel.app) · Repo: [DwiBInaFitriono/Bimbingan_Konseling](https://github.com/DwiBInaFitriono/Bimbingan_Konseling)

</details>
